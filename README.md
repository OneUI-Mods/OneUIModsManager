# OneUI Mods Manager

OneUI-Modsのアプリを一覧で確認し、GitHub Releaseから更新できるAndroidアプリです。

## できること

- インストール済み／未インストールのアプリを検索・絞り込み
- GitHubの公開リリースと端末のバージョンを比較
- 「実験版も表示」スイッチで安定版と実験版を切り替え
- 変更内容を確認してAPKをダウンロードし、Androidの確認画面から更新
- 更新APKをまとめて準備し、順番にインストール
- パッケージ名・署名証明書・SHA-256・バージョンを照合
- 日本語／英語、ライト／ダークモード、アプリ内ライセンス一覧
- 管理対象の追加・変更は公開カタログから取得。管理アプリ本体の更新は不要

## 対応環境

Android 16・17。管理アプリ自体にroot・Vectorは不要です。各モジュールの対応OSと導入条件は、それぞれのREADMEをご確認ください。

## 導入と更新

[Releases](https://github.com/OneUI-Mods/OneUIModsManager/releases)から署名済みの`*-release.apk`をインストールしてください。初めてこのアプリから更新するときは、Androidの「この提供元を許可」が必要です。

「アプリ」で対象を選び、変更内容を確認してダウンロードします。「更新」では更新のあるアプリをまとめて準備できます。インストールは毎回Androidの確認画面で承認します。モジュールの更新後に必要な再読み込みは、対象アプリの案内に従ってください。管理アプリが自動で端末を再起動することはありません。

初期設定は実験版を含みます。設定のスイッチをOFFにすると安定版だけが候補になります。実験版を導入済みの場合も、古い安定版へ自動で戻すことはありません。

## アプリ一覧の更新

一覧はこのリポジトリの[`catalog/apps.json`](catalog/apps.json)を取得します。公開カタログへアプリが追加された場合やパッケージ名が変わった場合も、管理アプリを入れ直す必要はありません。「更新を確認」を押すと、最新の一覧と各アプリのGitHub Releaseを確認します。起動時の自動確認でも取得します。

通信できない場合は前回取得した一覧を使い、初回の通信前は同梱の一覧を表示します。カタログの登録方法は[開発者向けドキュメント](docs/development.md#カタログ)にまとめています。

## 通信とプライバシー

GitHubの公開カタログ・リリース情報・APKだけを取得します。GitHubログインは不要です。インストール済みアプリの判定は端末内で行い、一覧や設定を送信しません。利用状況の解析・広告はありません。

起動時の自動確認は前回の完了から6時間以上空いたときに行います。設定でOFFにできます。定期的にバックグラウンドで巡回する機能ではありません。通信できないときは前回の情報を表示し、GitHubの回数制限に達したときは再試行可能な時刻を表示します。

## 制限

- OneUI-Modsのカタログに登録されたアプリが対象です。
- 配布側で確認できるAPKが1本に定まらないリリースは対象外です。
- SHA-256を確認できないAPKや、証明書が一致しないAPKはインストールに進めません。
- ダウンロードを途中で終了した場合、再開時は最初から取得します。
- 同じ名前のバージョンでも登録済みのビルド番号で比較します。未登録の特殊なバージョン表記は判定を保留する場合があります。
- 初期版のため、一部の端末・インストーラーでは追加の確認操作が必要な場合があります。
